# Үнэлэмж

Газар, үйлчилгээний үнэлгээний сайт. Сайт нь GitHub Pages дээр, сэтгэгдлүүд Supabase дээр хадгалагдана.

| Хаяг | Юу |
|---|---|
| `/usukh-ugii/` | Өсөх Өгий амралтын газрын хуудас: үнэлгээ, сэтгэгдэл, үнэлгээ өгөх |
| `/usukh-ugii/#review` | Үнэлгээ өгөх цонхыг шууд нээнэ (QR кодонд үүнийг ашиглана) |
| `/admin/` | Эзэмшигч: сэтгэгдэлд хариулах, зүй бус сэтгэгдлийг нуух |

## Нэг удаагийн тохиргоо

1. Supabase-д **тусдаа** төсөл үүсгэнэ (GRIT-ийн төслөөс тусад нь).
2. SQL Editor дээр `supabase/001_reviews.sql`-ийг ажиллуулна.
3. Газраа нэмж, эзэмшигчийн түлхүүрийг тохируулна (түлхүүрийг зөвхөн эзэмшигч мэднэ):
   ```sql
   select unelemj.add_place('usukh-ugii', 'Өсөх Өгий', 'Амралтын газар', 'Өгий нуур', 'урт-нууц-түлхүүр');
   ```
4. Project Settings → API-аас **Project URL** болон **publishable (anon) key**-г `assets/config.js`-д бичнэ.
   Энэ түлхүүр нийтэд ил байх зориулалттай: хүснэгтүүдийг шууд уншиж чадахгүй, зөвхөн `ue_*` функцуудыг дуудна.
5. GitHub → Settings → Pages: `main` салбараас нийтэлнэ.
6. GitHub → Settings → Secrets and variables → Actions → **Variables**: `SUPABASE_URL`, `SUPABASE_KEY`-г
   config.js-тэй ижил утгаар нэмнэ. Ингэснээр `keepalive` өдөр бүр ажиллаж, үнэгүй төсөл түр зогсохгүй.

## Зураг, мэдээлэл

`assets/config.js` доторх `UE_PLACES`-д тайлбар, улирал, утас, зургуудыг бичнэ.
Зургийг `usukh-ugii/photos/` хавтаст хийнэ (өргөн нь 1600px орчим, JPG). Зөвхөн өөрсдийн эзэмшдэг зургийг ашиглана.

## Дүрэм

- Хэн ч бүртгэлгүйгээр үнэлж болно. Нэг төхөөрөмжөөс нэг газарт өдөрт нэг удаа, нэг сүлжээнээс өдөрт 5 хүртэл.
- Эзэмшигч хариулж, нууж болно. Засах, устгах боломжгүй. Нуусан сэтгэгдэл дундаж оноонд тооцогдохгүй.
- Зохиомол сэтгэгдэл оруулахгүй.

## Шилжүүлэх, зарах

Гурван зүйлийг шинэ эзэмшигч рүү шилжүүлнэ: энэ GitHub репо, Supabase төсөл (Project Settings → Transfer),
домэйн. GRIT-тэй ямар ч холбоогүй.

## Google-ээс хайх

1. Supabase SQL Editor дээр `supabase/002_google_places.sql`-ийг ажиллуулна.
2. Google Cloud дээр **Places API (New)**-г идэвхжүүлж, API түлхүүр үүсгэнэ. Түлхүүрийг заавал хязгаарлана:
   - Application restrictions → **Websites**: `https://9yn5ddt5fy-tech.github.io/*` (дараа нь өөрийн домэйн)
   - API restrictions → зөвхөн **Places API (New)**
   - Quotas хэсэгт өдрийн дээд хязгаар тавина.
3. Түлхүүрийг `assets/config.js` доторх `UE_GOOGLE.key`-д бичнэ.

Google-ийн дүрмээр зөвхөн газрын ID-г хадгална. Нэр, хаяг, зургийг хуудас нээгдэх бүрт Google-ээс уншиж, «Google Maps» гэж эх сурвалжийг нь заана.
Google-ийн газар анхны үнэлгээгээ авахад өгөгдлийн санд үүснэ (хаяг нь `/p/?g=<Google place ID>`).
